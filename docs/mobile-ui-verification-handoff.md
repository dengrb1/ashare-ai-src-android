## 1. 背景与变更摘要

本次仅做**界面优化**，未改动数据层 / API / 业务逻辑：

1. **重做深色主题**：从近黑色中性灰（`#121317` / `#1B1C22`）改为**深蓝夜色**色系：页面背景 `#0E1524`、卡片 `#182130`，亮青（teal）主操作色 + 靛蓝（indigo）强调色。**不是纯黑**。
2. **修复 NavigationBar 紫灰底色**：补齐了 Material 3 的 `surfaceContainer*` 容器层，底部导航栏、对话框、日期选择器从 M3 默认紫灰变为蓝色调。
3. **卡片边缘微光**：`AppCard` 卡片顶部 2dp 处有一条主题色（深色=青色 / 浅色=墨绿）16% 透明度、向下渐隐的微光，形成"边缘光"层次。
4. **启动屏**：冷启动窗口背景改为与主题一致的 `#F7F8FA`（浅）/ `#0E1524`（深），消除启动时黑/白 flash。

**A 股约定**：红涨绿跌（涨 `#E53935`、跌 `#00A86B`、平 `#9E9E9E`），K 线 MA 线保持原色（5 日琥珀 `#F2A93B`、10 日靛蓝 `#3D5AFE`、20 日紫 `#AB47BC`）。

**主题切换**：App 默认"跟随系统"。在 **设置 → 外观** 有三档：`跟随系统 / 浅色 / 深色`，请三种都验证。

## 2. 构建与安装

前置：Android Studio（JDK 17）、已连接设备或模拟器（建议真机 + 截图工具）。

```bash
cd F:\code\ashare-ai-src-android
.\gradlew.bat assembleDebug
.\gradlew.bat installDebug
```

- Release 变体当前**无签名配置**（`build.gradle.kts` 未配 `signingConfig`），交付物以 **debug 安装包**为准进行视觉验证。
- 冷启动观察点：深色模式下启动屏应为深蓝 `#0E1524`，不应闪纯黑；浅色模式启动屏为 `#F7F8FA`，不应闪纯白。

## 4. 逐屏验证矩阵

> 建议每屏分别截「深色」「浅色」两张图。表格默认描述**深色模式**检查点。

| 屏幕 | 主要检查点 |
|---|---|
| 启动屏 / 冷启动 | 深色下无纯黑 flash，底色 `#0E1524`；浅色下无纯白 flash |
| 登录 | 背景 `#0E1524`；输入框描边 `#46526E`；登录按钮亮青 `#4DD6C0` |
| 首页 | 背景 `#0E1524`，卡片 `#182130`，卡片顶部有微光；总资产/涨跌幅用红涨绿跌；通知角标红色 |
| 行情 | 列表卡片微光；涨跌颜色正确（红/绿/灰） |
| 个股详情 | K 线 MA 线为琥珀/靛蓝/紫三色；涨跌幅红绿；日期/区间选择正常 |
| 研究 hub | 卡片、入口区块青色图标正常 |
| 每日研究 | 研究卡片 + 状态点：已完成绿、运行中青、失败红、FUSED 琥珀 |
| 报告 | 顶部日期选择器（弹层为蓝色调 `#182130`/`#EDF0F6`）；卡片微光 |
| 候选 / 组合 | 涨跌色正确；组合盈亏卡片红涨绿跌 |
| 卖出建议 | 建议卡片、FUSED 琥珀状态正常 |
| 回测 / 运行 | 运行状态色、进度指示正常；运行失败红色错误条 `errorContainer #5E2025` |
| 问答 | 对话气泡、输入框描边正常；深色下无白底 flash |
| 我的 | 卡片列表、个人资料区正常 |
| 设置 | 外观三档切换（跟随系统/浅色/深色）即时生效；开关滑块为青色 |
| 通知 | 列表卡片、未读标记红色 |
| 搜索 / 个人数据 | 常规卡片、文件操作按钮青色 |

**全局检查点（每屏都看）**：
- 底部 NavigationBar 5 个 tab：容器色 `#182130`（深）/ `#EDF0F6`（浅），**选中 tab 的指示器底色是靛蓝调 `#2E3650`（深）**，不是紫灰。
- 所有卡片顶部有**轻微**微光（16% 透明度、向下渐隐 2dp）——深色下是青色、浅色下是墨绿色，是"若有若无"的层次感，不应刺眼。
- 文字对比度：次级文字 `#A6AFC6` 在蓝底上清晰可读。
- 打开日期选择器（报告页/每日研究页）与任何弹窗：容器为蓝色调，无紫灰、无纯黑。
