# 连接版（Fusion）工作区策略文档

## 概述

本文档定义了 A股 AI 助手应用中「连接版（Fusion）」与「独立版（Local）」两个工作区的定位、功能边界和数据互通策略。

### 核心理念

- **独立版（Local）**：离线优先，隐私保护，单设备完整体验
- **连接版（Fusion）**：云端协同，企业级功能，多设备数据同步

两个工作区共享统一的 UI 主题和交互模式，但在数据存储、AI 能力和功能范围上有明确的差异化定位。

---

## 一、工作区定位

### 1.1 独立版（Local）

**目标用户**
- 重视数据隐私的个人投资者
- 网络环境不稳定的用户
- 追求纯本地体验的用户

**核心特性**
- **离线优先**：所有数据存储在本地，无需联网即可使用核心功能
- **隐私保护**：持仓、交易记录完全本地化，不上传云端
- **单设备**：数据仅在当前设备上，不跨设备同步
- **端侧 AI**：优先使用 HyperOS AI 引擎进行本地推理
- **离线回测**：基于本地历史数据的策略回测
- **端侧加密**：敏感数据在本地使用 Android Keystore 加密存储

**主要功能**
- 本地持仓管理
- 本地 AI 分析（研究报告解释、聊天助手）
- 离线行情查看（需预先下载）
- 本地策略回测
- 小米超级岛实时监控
- 本地数据导入导出

### 1.2 连接版（Fusion）

**目标用户**
- 需要多设备协同的专业投资者
- 团队协作场景（如投资小组、家庭理财）
- 追求更强 AI 能力和云端数据分析的用户

**核心特性**
- **云端同步**：数据存储在云端，多设备自动同步
- **团队协作**：支持多用户共享研究笔记、策略模板
- **高级 AI**：使用云端大模型（如 GPT-4、Claude Opus），能力更强
- **数据分析看板**：云端聚合分析，生成投资组合报告
- **多账户管理**：支持管理多个券商账户
- **实时行情推送**：WebSocket 实时行情，无需手动刷新

**主要功能**
- 云端持仓同步（多设备）
- 高级 AI 分析（投资组合优化、风险分析）
- 实时行情推送
- 团队协作看板
- 多账户管理
- 云端回测（更大数据集）
- 策略模板市场

## 三、数据互通策略

### 3.1 可共享数据（双向同步）

以下数据在两个工作区之间共享，用户可在设置中选择是否启用同步：

| 数据类型 | 说明 | 存储位置 |
|---------|------|---------|
| **主题设置** | 深色模式、玻璃态材质开关 | `SharedDataStore` |
| **通知偏好** | 超级岛开关、通知频率 | `SharedDataStore` |
| **语言设置** | 界面语言 | `SharedDataStore` |
| **AI 配置** | AI 提供商、模型选择（仅配置，不含 API Key） | `SharedDataStore` |

**实现机制**
- 使用 `SharedDataStore`（基于 DataStore Preferences）存储共享配置
- 工作区切换时自动调用 `syncToWorkspace()`
- 用户可在设置界面单独控制每项数据的同步开关

### 3.2 单向同步数据（连接版 → 独立版）

以下数据仅从连接版单向同步到独立版：

| 数据类型 | 说明 | 同步时机 |
|---------|------|---------|
| **策略模板** | 云端策略模板下载到本地 | 用户手动触发 |
| **AI 提示词库** | 云端优化的提示词模板 | 每周自动同步 |

### 3.3 完全隔离数据（不共享）

以下数据在两个工作区完全隔离，确保隐私和数据安全：

| 数据类型 | 说明 | 原因 |
|---------|------|------|
| **持仓数据** | 股票持仓、成本、数量 | 隐私敏感，不应跨工作区 |
| **交易记录** | 买入卖出历史 | 隐私敏感，不应跨工作区 |
| **研究笔记** | 用户自定义研究记录 | 工作区场景不同 |
| **回测结果** | 策略回测历史 | 数据源和引擎不同 |
| **API 密钥** | AI 提供商的 API Key | 安全敏感，独立管理 |

## 五、技术架构

### 5.1 独立版技术栈

```
┌─────────────────────────────────────────┐
│         独立版（Local Workspace）         │
├─────────────────────────────────────────┤
│ UI Layer: Jetpack Compose + Material 3 │
│ ViewModel: StateFlow + ViewModel        │
│ Repository: 本地数据源封装                │
│ Data Layer:                             │
│   - Room (持仓、交易、研究)               │
│   - DataStore (设置、缓存)               │
│   - SharedDataStore (共享配置)           │
│ AI Layer:                               │
│   - LocalInferenceDetector (端侧检测)   │
│   - AiCacheManager (缓存管理)            │
│   - AiPayloadBuilder (请求构建)          │
│ Notification: 超级岛 (FocusNotification) │
└─────────────────────────────────────────┘
```

### 5.2 连接版技术栈（规划）

```
┌─────────────────────────────────────────┐
│        连接版（Fusion Workspace）         │
├─────────────────────────────────────────┤
│ UI Layer: Jetpack Compose + Material 3 │
│ ViewModel: StateFlow + ViewModel        │
│ Repository: 云端 + 本地缓存               │
│ Data Layer:                             │
│   - Room (本地缓存)                      │
│   - Retrofit (云端 API)                 │
│   - WebSocket (实时行情)                 │
│   - SharedDataStore (共享配置)           │
│ AI Layer:                               │
│   - CloudAiService (云端推理)            │
│   - AiCacheManager (缓存管理)            │
│ Sync Layer:                             │
│   - WorkManager (后台同步)               │
│   - DataSyncService (增量同步)           │
│ Auth Layer:                             │
│   - OAuth 2.0 (用户认证)                 │
│   - JWT (会话管理)                       │
└─────────────────────────────────────────┘
```

### 5.3 共享模块

以下模块在两个工作区之间共享：

- `ui/theme/` - 主题系统（HybridTheme、GlassMorphism）
- `ui/components/` - 通用 UI 组件（AppCard、GlassControls）

## 七、隐私和安全

### 7.1 独立版隐私保护

- **数据本地化**：所有敏感数据存储在本地 SQLite 和 DataStore
- **端侧加密**：使用 Android Keystore 加密持仓和交易数据
- **无追踪**：不收集用户行为数据，不使用第三方分析 SDK
- **离线优先**：核心功能无需联网，减少数据泄露风险

### 7.2 连接版安全措施（规划）

- **传输加密**：所有云端通信使用 HTTPS + TLS 1.3
- **存储加密**：云端数据使用 AES-256 加密存储
- **访问控制**：OAuth 2.0 认证 + JWT 会话管理
- **审计日志**：记录所有敏感操作，支持合规审计
- **数据隔离**：多租户架构，确保用户数据隔离

### 7.3 用户控制权

- **数据导出**：支持一键导出所有数据（JSON 格式）
- **账户删除**：支持完全删除云端数据（连接版）
- **共享控制**：用户可精细控制哪些数据在工作区间共享
- **透明度**：设置界面明确显示当前数据存储位置和同步状态

## 十、总结

「连接版（Fusion）」与「独立版（Local）」的双工作区设计，旨在为不同需求的用户提供最佳体验：

- **独立版**：为重视隐私、追求纯本地体验的用户提供完整、快速、安全的工具
- **连接版**：为需要云端协同、高级 AI 和团队协作的专业用户提供企业级解决方案

两个工作区共享统一的 UI 主题和交互模式，确保用户切换时的连贯体验。通过精心设计的数据互通策略，既保护用户隐私，又提供灵活的配置同步能力。

**核心价值观**：隐私优先、用户控制、功能分层、体验统一。
